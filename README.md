# LLM Interview Lab

面向 LLM、Agent、后训练与推理岗位的互动面试学习实验室。

## 当前原型

- 六条岗位学习路线
- 带答案结构和追问的精选面试题
- 可交互的 KV Cache 显存估算器
- 保存在浏览器本地的复盘 Notes
- 课程、博客和经典论文入口
- 响应式布局和 PWA manifest

## 本地开发

```bash
npm install
npm run dev
```

## 发布

仓库包含 GitHub Pages 工作流。将代码推送到 `main` 并在仓库设置中选择 GitHub Actions 作为 Pages 发布源后，网站会发布到：

`https://yiding4869.github.io/llm-interview-lab/`
